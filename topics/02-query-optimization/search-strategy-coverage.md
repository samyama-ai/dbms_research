# Top-down vs. bottom-up search space coverage

> **Topic:** Query Optimization · **ID:** `02-query-optimization/search-strategy-coverage` · **Status:** partially-solved

## 1. Problem Statement

Two paradigms dominate plan search. **Bottom-up** DP (Selinger, System R; DPccp) builds optimal plans for small relation sets and combines them upward. **Top-down** memoization with branch-and-bound (Volcano/Cascades) recursively decomposes the goal expression, applying transformation rules and propagating cost bounds downward. Folklore holds they explore "the same space," but their **reachable plans, pruning power, and termination guarantees differ**. The problem: **precisely characterize the set of plans each paradigm can reach for a given rule/operator set, and unify their optimality and complexity guarantees.**

- **Coverage (decision) variant:** Given a logical query and a transformation-rule set $\mathcal{R}$, is plan $p$ reachable by top-down derivation? by bottom-up DP? Are the two reachable sets equal?
- **Optimization variant:** Does each paradigm return a global optimum over its reachable set, and under what conditions are those optima equal?
- **Complexity variant:** Compare the number of generated subplans / rule firings (work) between paradigms on the same input, separating *enumeration* from *pruning*.

"Solving" means a theorem equating (or separating) reachable sets and a unified cost/pruning model, not benchmark anecdotes.

## 2. Mathematical Foundations

Model the search as exploration of an **AND/OR graph** (the *memo*): OR-nodes are logically-equivalent expression groups, AND-nodes are operators with input groups. A plan is a choice of one AND-child per reached OR-node — a *plan tree* embedded in the memo. Transformation rules $\mathcal{R}$ generate the logical equivalence class; the memo is the fixpoint of applying $\mathcal{R}$. Bottom-up DP enumerates **connected subgraphs** and computes $\mathrm{best}[S]$ for all $S$; top-down computes $\mathrm{best}[\text{goal}]$ lazily, expanding a group only when demanded, and uses a cost **upper bound** $UB$ to prune: a subgroup whose lower-bound cost $\ge UB$ is never optimized (branch-and-bound). Key formal objects: the **principle of optimality** (required by both), the **group lower bound** $LB(g)$ used for top-down pruning, and **memoization equivalence** — both paradigms compute the same $\mathrm{best}[\cdot]$ table if they reach the same groups. The separation arises because top-down can *avoid generating* groups not on any below-$UB$ path, whereas bottom-up generates all of them.

## 3. State of the Art (SOTA)

- **Theory SOTA:** Shapiro et al. and DeHaan–Tompa (*Optimal Top-Down Join Enumeration*, SIGMOD 2007) gave a top-down enumerator that generates exactly the csg-cmp-pairs — proving top-down can match bottom-up DPccp's optimal enumeration. Fender & Moerkotte (*Top-Down Plan Generation*, BTW/ICDE 2011–2013) extended optimal top-down enumeration to hypergraphs (TDMinCutLazy / TDMinCutConservative), establishing parity with DPhyp.
- **Systems SOTA:** Cascades/Columbia and its descendants — Microsoft SQL Server, Greenplum/Pivotal **Orca** (Soliman et al., SIGMOD 2014), Apache Calcite (Volcano planner), CockroachDB — use top-down memoization with branch-and-bound. PostgreSQL, DuckDB, HyPer/Umbra use bottom-up DP. Both are deployed at scale; the choice is engineering-driven (rule extensibility favors top-down; predictable enumeration favors bottom-up).

## 4. Upper Bound

With optimal enumeration on both sides, each paradigm performs $O(\\#\text{ccp}(G))$ join-pair generations plus per-pair cost work, with memo space $O(2^n)$ (RAM model). Top-down's branch-and-bound can reduce *realized* work below $\\#\text{ccp}$ when the bound prunes subgraphs, but its **worst case equals bottom-up** (no pruning when costs are flat). Thus the proven upper bound on reachable-set computation is identical: both reach the full equivalence class generated by $\mathcal{R}$, and both compute the global optimum over it.

## 5. Lower Bound

For the bushy model, $\\#\text{ccp}(G)$ is the unconditional lower bound on enumeration for *both* paradigms (Section *dp-enumeration-scaling*); DeHaan–Tompa and Fender–Moerkotte show top-down meets it, so neither paradigm is asymptotically cheaper in the worst case. Pruning gives no worst-case asymptotic improvement: adversarial cost functions force top-down to expand every group (the bound never bites). Optimal join ordering remaining NP-hard for general graphs bounds both paradigms from below in the exact-optimization model.

## 6. The Gap

The **reachable-set equivalence is essentially settled** for join enumeration: optimal top-down and bottom-up enumerators provably generate the same csg-cmp-pairs and the same optimum, so this slice is *closed*. What remains genuinely open: (1) a tight characterization of **pruning power** — for which workload/cost classes does branch-and-bound give an asymptotic, not just constant-factor, win, and can one prove input families where top-down is super-polynomially faster than bottom-up or vice versa? (2) coverage under **rich rule sets** beyond joins (subquery unnesting, aggregate pushdown, set operations), where the two paradigms' reachable sets are *not* obviously equal because rule applicability is order-sensitive (this connects to *transformation-rule-completeness* and *cascades-rule-scheduling*). (3) A single framework that unifies physical-property propagation (interesting orders) across both. Closing (1)–(3) needs a model that scores pruning and rule-driven reachability jointly.

## 7. Current Research (as of June 2026)

- **Unified enumerator frameworks** that instantiate as either paradigm and let pruning be analyzed independently (Moerkotte/Fender lineage, TUM). *(frontier — verify)*
- **Cascades formalization** efforts giving Orca/Calcite-style optimizers operational semantics so reachability and confluence can be proven (Calcite community; academic Cascades models). *(frontier — verify)*
- Comparative studies isolating planning quality from cardinality error to fairly score search strategies (links to *optimizer-benchmarking*).
- Top-down enumeration for **non-inner / outer joins and hypergraphs** with conflict-detection rules (Moerkotte–Neumann conflict detectors).

## 8. Future Work

- Provable separations (super-polynomial) between top-down B&B and bottom-up DP on identified workload families, or a proof none exist.
- Reachable-set equivalence theorems for full extensible rule sets, not just joins.
- A pruning-power complexity measure analogous to $\\#\text{ccp}$ for enumeration.
- Unified treatment of physical properties (orders, distribution) across paradigms.

## 10. Worked Example

Chain query $R_1 \!-\! R_2 \!-\! R_3$ (joins $R_1R_2$ and $R_2R_3$). Count the connected-subgraph / complement pairs (csg-cmp-pairs), the shared lower bound on enumeration for *both* paradigms.

Connected subsets: $\{1\},\{2\},\{3\},\{12\},\{23\},\{123\}$. The valid csg-cmp-pairs (unordered) are:
- $\{1\}\,|\,\{2\}$, $\{2\}\,|\,\{3\}$ (build the 2-way joins),
- $\{1\}\,|\,\{23\}$, $\{12\}\,|\,\{3\}$ (two ways to build $\{123\}$).

So $\\#\text{ccp}=4$.

**Bottom-up DPccp** generates all 4, filling $\mathrm{best}[\{12\}],\mathrm{best}[\{23\}],\mathrm{best}[\{123\}]$.

**Top-down** with $UB=\infty$ (flat costs) also expands all 4 — no pruning, worst case equals bottom-up. But suppose costing $\{12\}$ first yields $UB=50$, and the lower bound $LB(\{23\})=80>50$: top-down skips generating the $\{1\}|\{23\}$ pair entirely, doing 3 pair-generations instead of 4.

This is the settled slice: both reach the same optimum over the same $\\#\text{ccp}$ pairs; only *realized* work differs when the bound bites.
