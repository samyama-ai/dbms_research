# CLAUDE.md — DBMS Research catalog

## What this repo is
A catalog of 1000+ research problems in the DBMS space, one Markdown file per problem,
grouped under `topics/<NN-topic-slug>/`. Schema for every problem file: `TEMPLATE.md`.
Master topic index: `TAXONOMY.md`.

## Conventions
- **One problem = one file.** Filename is the problem slug, kebab-case, `.md`.
- Every problem file MUST contain all 9 sections from `TEMPLATE.md` in order.
- **References must be real.** Cite canonical work confidently; do NOT fabricate URLs,
  DOIs, or paper titles. If unsure of a URL, cite author/title/venue/year without a link.
- **Flag the frontier.** Any claim about 2025–2026 SOTA that exceeds reliable knowledge
  gets `*(frontier — verify)*` inline. Knowledge horizon ≈ January 2026.
- **Math first.** Each file states the formal model and the key theorem(s) it rests on.
- Upper/lower bounds must name the *model* they hold in (RAM, cell-probe, comm.
  complexity, fine-grained/SETH, NP, information-theoretic, etc.).

## Adding a topic or problem
1. Add/extend the topic dir under `topics/`, update its `README.md` index.
2. Add the problem `.md` (copy `TEMPLATE.md`), fill all sections.
3. Update `TAXONOMY.md` counts if a topic's problem count changes.
4. Keep the root `INDEX.md` (generated) in sync — it is the flat list of all problems.

## Build/maintenance
- `INDEX.md` is generated by walking `topics/*/*.md` — regenerate after bulk edits.
